name: memory-edit
description: 修改记忆：照用户的说法，改一条已经记下的记忆的内容、类型或范围。
user-only: true
---

用户要改一条已经记下的记忆。

1. 先找到是哪一条：在系统提示的"Memory"清单里找，找不到再用 `recall` 的 `query` 查。拿不准是哪一条时，列出几条候选问用户，不要猜。
2. 那条另有细节的（清单里末尾带 `+`），先用 `recall` 读出来。
3. 用 `remember` 加上 `replaces`（那条的名字）写成改好的样子：内容、类型、范围照用户说的改，其余保持原样，原有的细节一起写回去。没有 `remember` 这个工具，说明这个模型服务只能读记忆，告诉用户到记忆页（侧栏的"记忆"）里改。
4. 改完说一句改成了什么。改过的内容从下一个对话起进入清单。
