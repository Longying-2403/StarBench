---
name: memory
description: 查看记忆：列出这个对话带着的记忆，或者按用户给的词查找。
user-only: true
---

用户想知道你记得哪些关于他和这个工作区的事。这一步只看，不改任何记忆。

1. 系统提示最后的"Memory"一节列着这个对话带着的记忆：每条一行，开头方括号里是类型，末尾 `#` 后面是它的名字，带 `+` 的另有细节。没有这一节，说明这个模型服务没有在用记忆，告诉用户可以到记忆页（侧栏的"记忆"）里改。
2. 用户这条消息里给了词，就用 `recall` 的 `query` 查找，清单放不下的记忆也查得到；没给词，就照清单全部列出。
3. 分"全局"和"本工作区"两组列出，每条写类型、内容和名字。有细节的，用户问起再用 `recall` 读出来。
4. 一条都没有时直说，并告诉用户可以直接说"记住……"，或者用 /memory-add 加一条。
5. 最后提一句：记忆页里可以直接修改和删除。
