---
name: memory-add
description: 记住：把用户这条消息里说的事记成记忆，以后的对话也用得上；范围和类型可以写明。
user-only: true
---

用户要你把这条消息里说的事记下来。

1. 一件事记一条，用 `remember` 保存。用户一次说了几件事，就分开记几条。没有 `remember` 这个工具，说明这个模型服务只能读记忆：告诉用户换一个服务，或者到记忆页（侧栏的"记忆"）里自己加。
2. 内容照用户的意思写成一句，尽量短，最多 150 个字；原因和做法放进 `details`。
3. 类型：关于用户本人和习惯的用 `user`；用户的纠正、或者确认过的做法用 `feedback`；这个项目代码里看不出来的决定和约束用 `project`；东西放在哪里用 `reference`。
4. 范围：用户说了"全局"或者"只记在这个项目"就照办；没说时，`user` 和 `feedback` 记成全局，`project` 和 `reference` 记在本工作区。
5. 清单里已经有意思相同的一条，就用 `replaces` 更新那一条，不要再记一条。
6. 不记密钥、密码这一类东西。用户坚持要记的，应用会先问用户一次。
7. 记完用一两句话说记了什么、记在哪个范围。新记的从下一个对话起才出现在清单里。
