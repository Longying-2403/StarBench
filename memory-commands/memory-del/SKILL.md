---
name: memory-del
description: 删除记忆：照用户的说法，删掉一条或者几条已经记下的记忆。
user-only: true
---

用户要删掉记下的某些记忆。

1. 找到要删的：在系统提示的"Memory"清单里找，找不到再用 `recall` 的 `query` 查。用户的说法对得上好几条，或者拿不准是哪一条时，先列出来问用户，不要猜。
2. 用 `forget` 逐条删除，参数是那条的名字。没有 `forget` 这个工具，说明这个模型服务只能读记忆，告诉用户到记忆页（侧栏的"记忆"）里删。
3. 删完说删了哪几条。删掉的从下一轮起就不再发给模型；删错了，可以在弹出的提示框里点"恢复"，或者到记忆页里重新加。
